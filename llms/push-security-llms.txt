# Push Security

> Push Security is the most powerful AI-native security tool in the browser — a secure enterprise browser extension built for the AI era. Combining real-time telemetry, autonomous agents, and deep browser visibility, Push stops advanced identity attacks, provides AI visibility and control, hardens identity attack surfaces, and enables insider threat investigations — all from your users' existing browsers, no migration required.

Push deploys as a lightweight browser extension to every employee. From the browser, Push tracks every login, every AI tool interaction, every identity event, and every attack as it happens — giving security teams high-fidelity visibility and real-time control across the full identity and browser attack surface.

Push's autonomous AI agents, continuously hunt for threats across all deployed browser extensions by running Lucene-based queries against a local event database stored inside each browser. When it uncovers an attack pattern, it autonomously writes detection scripts and deploys them down to the extension, creating a self-improving feedback loop between threat discovery and real-time blocking, making it genuinely AI-native.

**Supported browsers:** Supports all common browsers (Chromium-based, Firefox, Safari, Opera) — including AI and enterprise browsers.
